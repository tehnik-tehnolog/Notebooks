# Russian-English TTF Set: 25 Typefaces × 3 Styles

The archive contains **75 TTF files**: `Regular`, `Bold`, and `Italic` versions have been prepared for each entry. Each file has been verified to include the full Basic Latin and Russian alphabets, including `Ё/ё`.

## Style Matrix Details

* **Fira Code** and **Manrope** do not have official standalone Italic versions; the archive includes carefully prepared oblique variants derived from the open-source Roman files.
* The current official **Source Code Pro Italic** lacks Cyrillic characters in its Unicode map; therefore, the Italic version included here was created from the open-source Roman file while retaining the full Russian alphabet.
* The official **PT Mono** family consists of only a single style. The Bold and Italic versions in this archive are marked as synthetic variants to ensure the matrix contains the required three files.
* **STIX Two Math** is officially released only in Regular. The Bold and Italic slots contain the corresponding official **STIX Two Text Bold** and **STIX Two Text Italic** fonts—the companion text family from the same project, which includes Cyrillic support.
* The current official Unicode map for **TeX Gyre Termes** lacks Cyrillic support. This entry has been replaced with the open-source Cyrillic-supporting **Noto Serif** and renamed `TeX-Gyre-Termes-Compatible-Noto-Serif`.
