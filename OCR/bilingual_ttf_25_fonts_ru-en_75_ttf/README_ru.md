# Русско-английский комплект TTF: 25 гарнитур × 3 начертания

В архиве находятся **75 TTF-файлов**: для каждой позиции подготовлены `Regular`, `Bold` и `Italic`. Каждый файл проверен на наличие полного базового латинского и русского алфавитов, включая `Ё/ё`.

## Особенности матрицы начертаний

* **Fira Code** и **Manrope** не выпускают самостоятельный официальный Italic: в составе лежат аккуратно подготовленные наклонные варианты из открытых Roman-файлов.
* Текущий официальный **Source Code Pro Italic** не содержит кириллицу в Unicode-карте, поэтому его позиция Italic создана на основе открытого Roman-файла с сохранением полного русского алфавита.
* **PT Mono** в официальном семействе имеет одно начертание. Bold и Italic в архиве отмечены как синтетические варианты, чтобы матрица содержала ровно три требуемых файла.
* **STIX Two Math** официально выпускается только в Regular. Его позиции Bold и Italic содержат официальные соответствующие **STIX Two Text Bold/Italic** — это сопровождающее текстовое семейство того же проекта, с кириллицей.
* Текущая официальная Unicode-карта **TeX Gyre Termes** не содержит кириллицу. Его позиция заменена на открытую кириллическую Noto Serif и названа `TeX-Gyre-Termes-Compatible-Noto-Serif`.

## Лицензии и источники

Шрифты из Google Fonts публикуются в соответствии с лицензиями SIL Open Font License 1.1 либо Apache License 2.0. IBM Plex и STIX Two распространяются по SIL OFL 1.1; DejaVu Sans имеет собственную свободную лицензию. Полные применимые тексты присутствуют в каталоге `LICENSES`.

Основные первоисточники: [Google Fonts](https://github.com/google/fonts), [IBM Plex](https://github.com/IBM/plex), [STIX fonts](https://github.com/stipub/stixfonts) и [CTAN TeX Gyre](https://ctan.org/pkg/tex-gyre). Для ограничения распространения шрифтов Windows см. [Microsoft Font Redistribution FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq).
